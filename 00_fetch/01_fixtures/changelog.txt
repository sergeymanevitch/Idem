# Changelog

All notable changes to the Example API are listed here, newest first.

## 2.1.0 — 2026-09-01

- Breaking: the GET /v1/users endpoint now returns email_verified.
- Deprecated the sort parameter.
  - Use order_by instead.
  - Removal is planned for 3.0.
    - Warning headers from 2.2.
- Added a limit parameter.
  The default is 50 & the maximum is 500.
- ### Webhooks
  New events for refunds.

Request bodies larger than 1 MB are rejected with 413.
