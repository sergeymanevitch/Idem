    399: ## Large changes
    400: 
    401: * The Nylas Python SDK now fully supports both Python 2.7 and Python 3.3+.
    402: * The SDK has a new dependency: the
    403:   [URLObject](https://pypi.python.org/pypi/URLObject) library.
    404:   This dependency will be automatically installed when you upgrade.
    405: * The SDK now automatically converts between timestamps and Python datetime
    406:   objects. These automatic conversions are opt-in: your existing code should
    407:   continue to work unmodified. See the "Timestamps and Datetimes"
    408:   section of this document for more information.
    409: 
    410: ## Small changes
    411: 
    412: * The SDK now has over 95% automated test coverage.
    413: * Previously, trying to access the following model properties would raise an error:
    414:   `Folder.threads`, `Folder.messages`, `Label.threads`, `Label.messages`.
    415:   These properties should now work as expected.
    416: * The `Thread` model now exposes the `last_message_received_timestamp` and
    417:   `last_message_sent_timestamp` properties, obtained from the Nylas API.
    418: * Previously, if you created a `Draft` object, saved it, and then
    419:   deleted it without modifying it further, the deletion would fail silently.
    420:   Now, the SDK will actually attempt to delete a newly-saved `Draft` object,
    421:   and will raise an error if it is unable to do so.
    422: * Previously, you could initialize an `APIClient` with an `api_server`
    423:   value set to an `http://` URL. Now, `APIClient` will verify that the
    424:   `api_server` value starts with `https://`, and will raise an error if it
    425:   does not.
    426: * The `APIClient` constructor no longers accepts the `auth_server` argument,
    427:   as it was never used for anything.
    428: * The `nylas.client.util.url_concat` and `nylas.client.util.generate_id`
    429:   functions have been removed. These functions were meant for internal use,
    430:   and were never documented or expected to be used by others.
    431: * You can now pass a `state` argument to `APIClient.authentication_url`,
    432:   as per the OAuth 2.0 spec.
    433: 
    434: ## Timestamps and Datetimes
    435: 
    436: Some properties in the Nylas API use timestamp integers to represent a specific
    437: moment in time, such as `Message.date`. The Python SDK now exposes new properties
    438: that have converted these existing properties from integers to Python datetime
    439: objects. You can still access the existing properties to get the timestamp
    440: integer -- these new properties are just a convenient way to access Python
    441: datetime objects, if you want them.
    442: 
    443: This table summarizes the new datetime properties, and which existing timestamp
    444: properties they match up with.
    445: 
    446: | New Property (datetime)           | Existing Property (timestamp)            |
    447: | --------------------------------- | ---------------------------------------- |
    448: | `Message.received_at`             | `Message.date`                           |
    449: | `Thread.first_message_at`         | `Thread.first_message_timestamp`         |
    450: | `Thread.last_message_at`          | `Thread.last_message_timestamp`          |
    451: | `Thread.last_message_received_at` | `Thread.last_message_received_timestamp` |
    452: | `Thread.last_message_sent_at`     | `Thread.last_message_sent_timestamp`     |
    453: | `Draft.last_modified_at`          | `Draft.date`                             |
    454: | `Event.original_start_at`         | `Event.original_start_time`              |
    455: 
    456: You can also use datetime objects when filtering on models with the `.where()`
    457: method. For example, if you wanted to find all messages that were received
    458: before Jan 1, 2015, previously you would run this code:
    459: 
    460: ```python
    461: client.messages.where(received_before=1420070400).all()
    462: ```
    463: 
    464: That code will still work, but if you prefer, you can run this code instead:
    465: 
    466: ```python
    467: from datetime import datetime
    468: 
    469: client.messages.where(received_before=datetime(2015, 1, 1)).all()
    470: ```
    471: 
    472: You can now use datetimes with the following filters:
    473: 
    474: * `client.messages.where(received_before=datetime())`
    475: * `client.messages.where(received_after=datetime())`
    476: * `client.threads.where(last_message_before=datetime())`
    477: * `client.threads.where(last_message_after=datetime())`
    478: * `client.threads.where(started_before=datetime())`
    479: * `client.threads.where(started_after=datetime())`
